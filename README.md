# tools

직접 쓰려고 만든 작은 도구들. https://tools.nupa.moe/

## 개발 및 빌드

Node.js 24 이상을 사용합니다. 이 프로젝트는 브라우저 전용이므로 ONNX Runtime의 추가 Node/CUDA 설치는 생략합니다(CI에도 같은 환경 변수를 지정합니다).

```sh
ONNXRUNTIME_NODE_INSTALL=skip npm ci
npm run dev
```

PowerShell에서는 먼저 `$env:ONNXRUNTIME_NODE_INSTALL="skip"`을 설정하고 `npm ci`를 실행합니다.

```sh
npm run check
npm test
npm run build
```

Astro 정적 빌드 결과는 `dist/`입니다. 빌드 후 MediaPipe 1.0.1 실행 JS/WASM을 `dist/vendor/mediapipe-1.0.1/`로 복사해 같은 사이트에서 제공합니다. 사진 편집 UI는 Astryx Neutral 테마와 실제 Button/Slider를 사용하는 React island입니다. 메인 도구 목록에는 클라이언트 프레임워크 JS를 보내지 않습니다. 다른 도구는 Astro의 별도 island에서 다른 프레임워크를 사용할 수 있습니다.

## 사진 보정

- **밝기:** 노출·대비·밝은 영역·어두운 영역.
- **색감:** 색온도·색조·채도·생동감, 자연스럽게/따뜻하게/차분하게/흑백 프리셋.
- **피부:** MediaPipe 얼굴·몸 피부 마스크로 부드러움과 밝기 적용. 기존 피부색 휴리스틱은 제거.
- **초점:** 직접 위치 지정, 인물 유지, 깊이 초점. 사진 클릭/드래그 또는 사진 영역에 포커스를 두고 방향키로 위치 지정.
- **인물·배경:** 배경 유지/제거/단색, 인물 바깥 테두리의 두께·색, 마스크 경계와 부드러움 조절.
- **뽀샤시:** 전체 사진에 부드러운 빛 번짐. 피부 평활화와 독립.
- **플레어:** 부드러운 빛·빛줄기·렌즈 고스트의 위치·크기·강도.
- **사진 테두리:** 단색 여백·이중선·폴라로이드·둥근 모서리. 원본을 축소하지 않고 외부 여백 추가.
- **누르고 비교:** 원본 보기/이전 보기는 포인터 또는 Space/Enter를 누르는 동안만 표시. 바깥에서 손을 떼기, 포인터 취소, 포커스 상실, 탭 숨김에서 복귀. 토글 없음.
- **편집 이력:** 드래그 한 번이 실행 취소 한 단계. 최대 50단계, 다시 실행, 항목별 적용 켜기/끄기(값 유지), 항목별/전체 초기화. Ctrl/Cmd+Z, Shift+Ctrl/Cmd+Z 지원.
- **내 설정:** 편집값 한 세트를 localStorage에 저장/복원. 사진이나 분석 마스크는 저장하지 않음. 모델이 준비되지 않은 효과는 프리셋 복원 시 제외.

PNG는 투명도 유지, JPG는 품질 95%이며 투명 영역을 흰색으로 합성합니다. 배경 제거를 선택하면 저장 형식을 PNG로 바꿉니다. 비교 화면·분석 영역 표시·초점 조작 표시는 저장되지 않습니다.

입력은 JPG/PNG/WebP/AVIF이며 실제 디코딩은 브라우저 지원에 따릅니다. 최대 40MB·2,400만 화소·긴 변 8,192px입니다. 초과 입력은 알리고 거절하며 자동 축소하지 않습니다. 긴 변 1,400px 미리보기와 별개로, 저장 시 원본 픽셀에 같은 설정을 다시 적용합니다. 효과의 위치·반경·테두리 두께는 사진 크기에 비례합니다. 원본 파일은 바꾸지 않으며 새 `-edited` 파일로 저장합니다. EXIF 방향을 반영하고 촬영 메타데이터는 복사하지 않습니다. RAW/HDR/광색역 보존 편집은 지원하지 않습니다.

## 로컬 모델

| 모델 | 용도 | 로딩 및 실행 |
| --- | --- | --- |
| MediaPipe SelfieMulticlass (float32, revision 1) | 인물·피부·머리카락·옷·배경 분리 | 사진을 열면 별도 classic Worker에서 로드. GPU 우선, 초기화 또는 첫 추론 실패 시 CPU 재시도 |
| Depth Anything V2 Small ONNX | 상대 깊이에 따른 초점 | 명시적으로 기능을 선택할 때 로드. Transformers.js 4.3.1 + WebGPU, CPU 대체 실행 없음 |

EmbeddingGemma는 포함하지 않습니다. 모델 로딩 중/실패 시 해당 모델이 필요한 기능만 비활성화합니다. 일반 보정·저장은 계속 가능합니다. MediaPipe 분석 결과와 깊이 지도는 사진마다 보관하고 슬라이더 조작에 재사용합니다. 새 사진으로 바꾸면 이전 사진의 진행 중 추론을 취소하고 오래된 결과는 무시합니다.

MediaPipe 모델 약 16.4MB는 Google Storage, 깊이 모델은 Hugging Face에서 다운로드합니다. 전자는 Cache Storage, 후자는 Transformers.js 브라우저 캐시를 사용하며 용량 부족 시 캐시 저장에 실패할 수 있습니다. 모델 실행에는 초기화/추론 버퍼가 추가로 필요합니다. 사진 픽셀은 외부로 전송하지 않으며 서버 API·로그인·API 키를 사용하지 않습니다.

인물 분리 입력은 256×256으로, 머리카락·손가락·액세서리·작은 인물·아바타 등에서 오차가 생길 수 있습니다. 배경 제거는 confidence 마스크를 사용한 컷아웃이며 전문 고해상도 매팅과 동일하지 않습니다. 깊이는 단안 사진의 상대적 추정값으로 실제 거리 측정이 아닙니다. 배경/초점 블러는 보호된 영역의 색이 배경으로 번지는 것을 줄이는 정규화 필터로 합성합니다. 렌즈의 물리적 보케를 완전히 재현하지는 않습니다.

## 도구 추가 및 배포

`src/data/tools.ts`에 이름·한 줄 설명·카테고리·처리 정보를 등록하고 `src/pages/<slug>.astro`에 페이지를 추가합니다. 제목 바로 아래에 서버 사용 여부와 정확한 로컬 모델명을 표시합니다. 메인에는 동작하는 도구만 나열하며 홍보 섹션/예고 항목을 넣지 않습니다. 데스크톱은 화면 높이에 맞춘 작업 영역, 모바일은 자연스러운 스크롤을 사용합니다.

`main` push 시 GitHub Actions가 타입 검사·테스트·정적 빌드 후 GitHub Pages에 배포합니다. Pull request는 검사/빌드만 수행합니다. 배포 주소는 **https://tools.nupa.moe/**, `SITE_URL=https://tools.nupa.moe`, `BASE_PATH=/`이며 `public/CNAME`도 동일 도메인을 가리킵니다. GitHub Pages에서 해당 커스텀 도메인과 HTTPS가 설정되어 있어야 합니다. 다른 호스팅의 하위 경로는 `BASE_PATH`로 지정할 수 있습니다.

## 검증 범위

픽셀 처리, 모델 마스크 적용, 원본/알파 보존, 초점과 배경 경계, 프레임 크기, 편집 이력, 프리셋 검증, 실제 React HoldButton의 포인터/키보드/포커스 이벤트를 자동 검사합니다. MediaPipe Worker의 GPU 실패→CPU 재시도와 마스크 복사/해제, 모델 클라이언트의 로딩/완료/취소 처리도 검사합니다. Worker 단위 테스트는 모의 런타임을 사용하므로 실제 브라우저 추론 테스트를 대체하지 않습니다.

별도 LiteRT CPU 런타임에서 공식 공개 샘플 사진 한 장을 실제 SelfieMulticlass 모델로 분석하고, 피부 마스크·배경 블러·투명 배경/흰 테두리·빛 효과·프레임의 픽셀 결과를 시각 확인했습니다.

이 실행 환경에는 지원되는 브라우저 제어 도구가 없어 실제 브라우저에서 GPU/CPU 추론, 파일 선택/다운로드 및 화면 크기별 레이아웃을 육안 검증하지 못했습니다. 모델 정확도와 처리 시간은 사용하는 사진·브라우저·기기에 따라 확인이 필요합니다.
