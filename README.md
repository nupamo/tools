# tools

직접 쓰려고 만든 작은 도구들. https://tools.nupa.moe/

## 개발 및 배포

Node.js 24 이상. 브라우저 전용 ONNX 런타임을 사용하므로 Node/CUDA 추가 설치는 생략합니다.

```sh
ONNXRUNTIME_NODE_INSTALL=skip npm ci
npm run dev
npm run check
npm test
npm run build
```

PowerShell: `$env:ONNXRUNTIME_NODE_INSTALL="skip"` 설정 후 `npm ci`.

Astro 정적 출력은 `dist/`입니다. Astryx Neutral의 실제 Button/Slider를 사용하는 React island에 편집 UI를 한정합니다. 메인 목록은 프레임워크 JS를 보내지 않습니다. 새 도구는 `src/data/tools.ts`와 `src/pages/<slug>.astro`에 등록합니다.

`main` push 시 GitHub Actions가 검사·테스트·빌드 후 GitHub Pages에 배포합니다. `SITE_URL=https://tools.nupa.moe`, `BASE_PATH=/`, `public/CNAME=tools.nupa.moe`입니다. 다른 호스팅의 하위 경로는 `BASE_PATH`로 지정할 수 있습니다.

## 사진 보정

- 오른쪽 **프리셋/고급** 탭. 프리셋에는 기본 색감과 내 프리셋을, 고급에는 개별 효과를 표시합니다. 모달은 사용하지 않습니다.
- 내 프리셋은 이름으로 여러 개 저장·적용·덮어쓰기·삭제합니다. localStorage의 `tools-photo-presets-v2`에 편집값만 보관하며, 기존 `tools-photo-preset-v1`도 한 번 옮깁니다. 사진·깊이 지도는 저장하지 않습니다. 저장 실패 시 기존 목록을 유지하고 오류를 표시합니다.
- 밝기: 노출·대비·밝은 영역·어두운 영역. 색감: 색온도·색조·채도·생동감.
- 초점: 직접 위치 지정 또는 상대 깊이. 깊이 초점의 **초점 깊이** 슬라이더(0~100)와 **선명한 깊이 범위**를 조절합니다. 사진 클릭/드래그 또는 방향키로 해당 위치의 깊이를 선택할 수도 있습니다.
- 뽀샤시 기본값: 강도 **0**(꺼짐), 빛 번짐 크기 **20**.
- 플레어 기본값: **없음**. 부드러운 빛·빛줄기·렌즈 고스트를 고르면 강도 **50**, 크기 **50**으로 시작합니다.
- 테두리: 단색 여백·이중선·폴라로이드는 외부 여백을 더합니다. 둥근 모서리는 원본 크기에서 모서리만 투명하게 자르고 PNG로 전환합니다.
- 피부·인물/배경·인물 유지 기능과 MediaPipe 모델 의존성을 제거했습니다. 이전 프리셋의 제거된 항목은 무시하고 인물 초점은 꺼짐으로 복원합니다.
- 별도의 적용 스위치는 없습니다. 각 항목은 **없음** 선택(초점·플레어·테두리)이나 값 **0**(밝기·색감·뽀샤시)이 기본 상태이며, 새 사진은 원본 그대로 보입니다. 초기화하면 이 기본 상태로 돌아갑니다. 적용 스위치가 있던 이전 프리셋은 꺼져 있던 항목을 기본 상태로 바꿔 불러옵니다.

원본 보기/이전 보기는 포인터 또는 Space/Enter를 누르는 동안만 표시됩니다. 바깥에서 손을 떼거나 취소/포커스 상실 시 복귀합니다. 같은 효과의 여러 조절은 실행 취소 한 단계로 묶으며 다른 탭이나 프리셋으로 옮기면 묶음을 끝냅니다. 최대 50단계, Ctrl/Cmd+Z 및 Shift+Ctrl/Cmd+Z 지원. 이전 보기는 현재 효과를 조절하기 전 결과입니다.

**깊이 지도 확인** 중에는 저장 버튼이 **깊이 지도 저장**으로 바뀝니다. 미리보기와 저장은 같은 회색조 변환을 사용하고, 사진 효과·프레임·조작 표시를 제외한 깊이 지도를 원본 가로/세로 크기의 PNG로 저장합니다. 지도 표시를 끄면 일반 사진 저장으로 돌아옵니다. 깊이 모델 출력의 보간이므로 원본 해상도의 새로운 깊이 정보를 생성하지는 않습니다.

일반 사진은 PNG(투명도 유지) 또는 JPG(품질 95%, 투명 영역 흰색)로 저장합니다. 원본 파일을 바꾸지 않고 `-edited` 파일을, 깊이는 `-depth.png`를 다운로드합니다. EXIF 방향을 반영하되 촬영 메타데이터는 복사하지 않습니다. RAW/HDR/광색역 보존 편집은 지원하지 않습니다.

입력은 JPG/PNG/WebP/AVIF, 최대 40MB·2,400만 화소·긴 변 8,192px입니다. 초과 입력은 알리고 거절하며 자동 축소하지 않습니다. 긴 변 1,400px 미리보기와 별개로 저장 시 원본 픽셀에 보정을 다시 적용합니다. 위치·반경·테두리 두께는 사진 크기에 비례합니다.

## 효과 엔진과 깊이 모델

사진 처리 Worker에서 PixiJS 8.22.0 + pixi-filters 6.1.5를 사용합니다. 노출·대비·채도는 `AdjustmentFilter`, 뽀샤시는 `BlurFilter` + `AdvancedBloomFilter`, 깊이/수동 초점은 40샘플 조리개 디스크 셰이더, 플레어는 절차적 광원/회절/고스트 셰이더로 처리합니다. 편집 시에만 렌더링하며 애니메이션 루프를 돌리지 않습니다.

미리보기·이전 결과·원본 저장은 같은 엔진과 설정을 사용합니다. 큰 사진은 텍스처 한도 내에서 주변 픽셀을 포함한 타일로 처리한 뒤 중앙 영역을 조립합니다. 프레임과 깊이 지도 픽셀은 CPU에서 조립합니다. OffscreenCanvas/WebGL2 초기화 실패 시 CPU 보정을 사용하고 엔진을 사진 크기 옆에 표시합니다. 실행 중 GPU 연결이 끊기면 오류를 표시합니다. CPU/GPU 사이의 효과 모양이 완전히 같지는 않습니다.

깊이 모델은 **onnx-community/depth-anything-v2-small-ONNX**입니다. Transformers.js 4.3.1 + WebGPU로만 실행하며 CPU 모델 대체 실행은 없습니다. 깊이 초점 선택 시 별도 Worker에서 모델을 다운로드합니다. 준비 중/실패 시 일반 효과·저장은 계속 사용할 수 있습니다. 깊이 프리셋을 적용하면 선택한 깊이를 보존한 채 모델을 준비합니다. 새 사진은 이전 추론을 취소하고 오래된 결과를 무시합니다.

모델은 Hugging Face에서 다운로드하고 Transformers.js 브라우저 캐시를 사용합니다. 사진 픽셀은 외부로 전송하지 않으며 서버 API·로그인·API 키를 사용하지 않습니다. 깊이는 단안 사진의 상대 추정값이며 실제 거리 측정이나 물리 렌즈의 보케를 완전히 재현하지 않습니다.

## 검증

픽셀/알파 보존, 깊이 초점·지도 저장 경로, 프레임 크기, 효과 단위 이력, 다중 프리셋 저장/복원/이전 및 저장 실패, React 패널과 누르고 비교의 DOM 이벤트를 자동 검사합니다. DOM 검사는 실제 브라우저 렌더링이나 모델 추론을 대체하지 않습니다.

네이티브 WebGL2 회귀 검사는 `scripts/check-photo-gpu.mjs`입니다. 선택 의존성 `webgl-node` 및 EGL/GLES 런타임을 별도 설치하고 모듈 절대 경로를 `PHOTO_WEBGL_MODULE`로 지정해 `node --import tsx scripts/check-photo-gpu.mjs`를 실행합니다. 이 런타임은 서비스 의존성에 포함하지 않습니다. 실제 브라우저의 WebGPU 추론·파일 입출력·화면별 레이아웃은 실행 환경 제약으로 확인하지 못했습니다.
